### Step 1: Push to GitHub
```powershell
cd "c:\Users\KUNAL KUMAR DUBEY\Sure-Health"
git add .
   git commit -m "Complete Triage Care website - ready for deployment"
git push origin main
```

### Step 2: Deploy on Render (FREE - 5 minutes)
1. Go to: **https://render.com**
2. Sign up/Login with GitHub
3. Click **"New +"** → **"Web Service"**
4. Select repository: **kunaldubey10/Sure-Health**
5. Configure:
   - **Name**: sure-health
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn flask_app:app`
   - **Instance Type**: Free
6. Click **"Create Web Service"**
7. Wait 5-10 minutes
8. **DONE!** 🎉 Your site is live!

### Step 3: Test Your Website
Visit your live URL and test all features!
